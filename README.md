**📝 Full-Featured To-Do App with Firebase**

&nbsp;&nbsp;A fully functional cross-platform To-Do app built with Flutter and Firebase, featuring real-time updates, Google &nbsp;&nbsp;&        Email authentication, and &nbsp;&nbsp;modern app architecture.<br> &nbsp;&nbsp;Check here on youtube : https://youtu.be/0_8LO0T6PeE

---
 **🚀 Features**

- **Add, update, and delete tasks with real-time updates using Firebase.**

- **Task completion toggle and swipe gestures for delete/complete actions.**

- **Authentication via Google Sign-In and Email & Password.**

- **Smooth navigation using go_router with Stateful Shell Routes.**

- **Real-time data fetching with StreamProvider for always up-to-date tasks.**

---

**🗂 Folder Structure**

```text
lib/
├── core/               # App-wide utilities, constants, and helpers
├── features/           # Feature-based structure
│   ├── auth/
│   ├── history/
│   ├── home/
│   ├── onboarding/
│   ├── profile/
│   ├── splash/
│   └── tasks/
│       ├── data/       # Data layer (models, data sources)
│       ├── domain/     # Domain layer (repositories, entities)
│       └── presentation/ # UI layer (screens, widgets)
├── shared/             # Shared widgets, components, and resources
└── main.dart
```

---
**🏗 Architecture**

- **Feature-based structure for better scalability and maintainability.**

- **Domain layer for repositories and business logic.**

- **Data layer for API/Firebase integration.**

- **Presentation layer for UI with Flutter widgets.**

- **State management using StreamProvider for real-time updates.**
- **Routing: go_router**

---
**⚡ Getting Started**

**Prerequisites**

Flutter SDK

Firebase project

Google services configuration for Google Sign-In

1. Installation

Clone the repository : git clone (your-repo-url)

cd (project-folder)

2. Install dependencies : flutter pub get

3. Run the app : flutter run
